One home. One shared plan.

GitHub Pages hosts the app. A Google Sheet can hold your household’s shared data. Until connected, Small Wins saves separately on each phone.

  1. Create a new blank Google Sheet in your Google account. Name it Small Wins.
  2. In the sheet, choose Extensions → Apps Script.
  3. Replace the editor contents with Code.gs, then save. Select setup in the function dropdown and click Run. Complete Google’s authorization yourself; this connects the script to this sheet.
  4. Choose Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Complete Google’s authorization yourself. If your account policy prevents public deployments, this option will not work.
  5. Copy the Web App URL ending in /exec.
  6. On your first phone, open Small Wins → Household settings → Connect shared storage and paste that URL. If storage is empty, this phone’s current plan will become the shared plan.
  7. Repeat on the other phone using exactly the same URL. It will load the shared plan. Each device keeps its own selected person.

Download a backup before connecting if either phone already contains changes you want to keep. The two separate plans are not automatically merged.

Anyone with the backend URL can read and edit its household plan. Keep the Google Sheet itself private; visitors do not need direct sheet access. Storage uses Google’s free quotas, which can limit requests. Share the main app URL with your wife and configure the backend once on each phone.
